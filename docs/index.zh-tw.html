三秒安裝

一行指令，systemd 管理，獨立 service user。

安裝程式會建立專用 jt-proxense 系統使用者、佈署強化過的 systemd unit、然後啟動服務。

Linux Debian · Ubuntu · RHEL · Rocky · Arch · openSUSE

需要 sudo 權限，Python 3.10+。

$curl -fsSL https://raw.githubusercontent.com/jasoncheng7115/jt-proxense/main/install.sh | sudo bash
裝完後： 用安裝程式印出的一次性 admin 密碼登入，然後在 設定 → 叢集 新增你的 PVE 連線 —— 免改設定檔，自動儲存並熱重載。預設網址：http://<your-server>:8098/。
更新

重跑安裝程式即可 (冪等，設定與資料保留)。

$curl -fsSL https://raw.githubusercontent.com/jasoncheng7115/jt-proxense/main/install.sh | sudo bash
解除安裝

完整移除服務、程式與資料 (不可逆)。

$curl -fsSL https://raw.githubusercontent.com/jasoncheng7115/jt-proxense/main/uninstall.sh | sudo bash
搬移

舊機匯出加密 bundle (含設定、資料庫與金鑰) → 新機安裝後匯入。

$sudo jt-proxense export-config bundle.enc # 舊機
$sudo jt-proxense import-config bundle.enc --force # 新機 (先完成安裝)

同一個叢集，看得到也動得了

用你需要的角度看它，然後動手。

用一個按鍵切換畫面，每一種都是同一份即時狀態的不同切片；需要出手時，操作也在同一個地方，走同一套認證與稽核。

Dashboard 概觀

全域總覽。資源儀錶、基礎建設加總、各叢集健康狀態一眼帶過。

Nodes 節點

每個節點獨立的 ECG 心電圖式指標。CPU / 記憶體 / I/O 即時波形。

Matrix 矩陣

每個 VM 一個彩色格子。可依狀態篩、依負載排、依節點分組 — 任意密度。

Radar 雷達

異常偵測雷達。突波、超門檻、離線節點立刻浮現。

Storage 儲存

每個儲存集區一格 treemap，大小依容量、顏色依使用率。壓力一眼可見。

Ceph

Ceph 叢集拓撲與即時 IOPS。OSD、Pool、recovery 狀態同畫面。

矩陣縮圖預覽

每台運作中虛擬機的 framebuffer 即時截圖，可依節點 / 類型 / 標籤分組。QEMU 透過迷你 RFB 3.8 client；LXC 透過 termproxy + vt100 emulator，CT 卡片直接顯示 shell 輸出而非黑框。點任一卡片開啟全尺寸放大，附 CRT 雜訊載入特效。

跨叢集遷移

Wizard 會剖析來源 VM、選擇目標叢集端點、取得 TLS fingerprint、列出磁碟與 NIC 對應。包含驗證、預檢、online / offline 模式、頻寬限速。Admin only；僅 QEMU (PVE API 限制)。失敗時跳出 toast 顯示可複製貼上的 qm unlock 解鎖指令。

儲存內容瀏覽

點任一 file-level 儲存區，依 content 動態出頁籤 (備份 / ISO 映像 / CT 範本 / 程式碼片段 / 匯入 / 磁碟映像 / CT 根目錄) — 只列出該儲存實際支援的類型。可排序清單、搜尋、含 audit 的刪除。Block-level (RBD / LVM / ZFSpool)只給瀏覽。

Telegraf line-protocol 接收器

InfluxDB v2 端點 /api/v2/write(token 認證、支援 gzip)。Per-host ring buffer 保留最新樣本，透過 /api/telegraf/{hosts,host} 讀取。在 PVE 各主機跑你自己的 Telegraf outputs.influxdb_v2，補強 API 輪詢之外的指標。

v0.2 — 認證 + 控制平面

現在多了可追溯性。

可選的認證、稽核日誌、角色式權限、VM & LXC 生命週期管理，一律 cyberpunk 風格。預設行為與 v0.1 相同 — 每一層都靠 config flag 啟用。

認證

Argon2id 密碼 + 12 小時 session、可選 PAM 後端 (系統帳號)、TOTP 雙因素含 8 組備用碼。Per-IP 暴力猜測速率限制。

稽核日誌

SQLite 附加式日誌。每次登入、角色變更、設定編輯、VM 操作都記錄。可 CSV 匯出、日期區間篩選、列展開細節。

VM-pattern RBAC

三種角色 (viewer / operator / admin)，可逐叢集 + 逐 VM 範圍授權。依名稱 (web-*) 或 tag (tag:prod)匹配。多條規則時最高層級獲勝。

VM + LXC 控制

開機 / 關機 / 重啟 / 暫停 / 遷移。批次操作可同時混合 VM 和 CT，最多 100 個 vmid / 次。預設關閉，需明確啟用。

緊急 CLI 後門

萬一被自己鎖在外面：jt-proxense auth disable 不需要服務在跑。重設密碼、清除遺失的 authenticator、修錯設定，全離線可做。出現「嘗試次數過多」？jt-proxense unlock 可清除單一 IP 的登入限流 (不會更動密碼)。

311 個測試，~3.5 分鐘

pytest 涵蓋 migration、認證、稽核 trigger、角色 gating、VM + CT dispatch、RBAC、主機升級狀態機、mock PVE。每次 push 在 CI 跑。

v0.4 – v0.8 — 機群維運

從單一叢集，到整片機群。

主動健康檢查、排程備份、滾動升級、匯出與帳號管理 — 這些是「跑一整片機群」的日常，不只是看著一個叢集。

健康監測 + Corosync

一頁匯總跨所有叢集的主動檢查：節點離線、CPU／記憶體過高、儲存將滿、Ceph 警告、憑證到期、待更新、HA 與複寫狀態 — 再加上從記錄推導的硬體問題(掃各節點 syslog 的 ECC／MCE／OOM／磁碟 I/O／檔案系統毀損)。專屬 Corosync 面板顯示仲裁、票數、各節點連結狀態與環延遲。

排程備份，PBS 感知

檢視與管理叢集層級的 vzdump 排程作業，也能從彈出視窗立即備份。當目標是 Proxmox Backup Server 時，壓縮選項會消失 (PBS 自己去重)，改浮現 PBS 專屬設定：notes-template、protected、失敗寄信。每台 VM 的備份歷史含還原與驗證。

使用者管理 + 2FA

WebUI 完整 RBAC：建立本機使用者、依叢集與 VM-pattern 授予角色、註冊／重設 TOTP、重發備援碼、停用／刪除。支援 local、PAM、LDAP 後端；每個變更操作都寫入僅可附加的稽核記錄。

ZFS 儲存集區維運

原廠 WebUI 只能「建立」儲存集區，之後就把你丟回命令列。這裡補上另一半：更換磁碟 (含開機碟的 ESP 處理)、新增 vdev 與 log / cache / special、RAIDZ 線上擴充、多 vdev 建池精靈、清理檢查與 TRIM，以及「影響範圍」——這個集區掛了會連帶失去哪些 PVE 儲存與客體。拓樸以視覺化方式呈現：集區 → vdev → 每顆磁碟，含 HDD/SSD/NVMe 圖示與容錯圓點 (還能再壞幾顆)。讀取全部走 PVE API，不需 SSH、也不會變更節點;只有維運操作需要 SSH，且一律先以 ZFS 自己的乾跑預覽、再輸入集區名稱確認。

滾動式主機升級

批次協調器：逐台疏散 → apt dist-upgrade(全自動) → 管理員確認重開機 → 可選搬回。三種疏散模式 (自動／手動／原地)，Ceph 感知 (設 noout、每台之間等所有 PG active+clean)，並有即時狀態面板標示失敗節點。

匯出成 OVA / Hyper-V

把 QEMU VM 轉成 VMware/VirtualBox OVA 或 Hyper-V VHDX，透過 SSH 在節點上執行、內建作業佇列 (轉換不受瀏覽器分頁關閉影響)。工具自動安裝 + 最新版檢查、暫存空間預檢、串流下載、產物 24 小時後自動清除。

節點維運 + 機群 SSH

每節點的網路介面檢視 (NIC／橋接／bond 連結與速率)、NTP/chrony 設定、磁碟 + SMART、服務、syslog。一鍵 SSH 金鑰佈署：手動授權一台，再由節點間 SSH 把主機金鑰擴散到其餘。從設定頁新增／移除整個叢集連線 — 免改 config.yaml，熱重載。
